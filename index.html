Link prediction for Amazon products and reviews

Built a ML link prediction model using Amazon Cell Phones and Accessories products and reviews data (4M entries) modeled as a graph to make products recommendations

Skills required: Data processing and analysis, sentiment analysis, ML, link prediction and graph theory

Reflection interference removal based on layer extraction of an image using their relative smoothness

Implemented a research paper optimization algorithm that removes reflection from a single image using its relative smoothness by convolving and deconvolving it with first and second order filters to reduce similarity between its reflection and its background

Skills required: Mathematics, code optimization, computer vision
